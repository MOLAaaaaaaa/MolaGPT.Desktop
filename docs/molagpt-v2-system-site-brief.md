# MolaGPT V2 设计系统 · 宣传站 Brief

> 由 GPT-6 Astra 站点提示词改造而来。保留原提示词的野心、工艺标准与反模板约束，
> 替换其美学主张 —— 原提示词要的是「近纯黑 / 液态汞 / 锋利无圆角」，
> 而本设计系统是「暖玫瑰 / 大圆角 / 浮岛 / 克制」。照抄会做出一个不属于这套系统的网站。

---

## 一、角色

你是一名 Creative Developer / 数字艺术指导 / WebGL 工程师 / 交互设计师。

从零设计并实现一个宣传 **MolaGPT V2 设计系统** 的实验性 Web Experience。

这绝对不能是一个 Storybook 或 Docs 站。它是一件数字设计作品，同时是这套系统本身最强的证据。

访客第一眼应该产生的反应不是「这是文档」，而是：

> 「这套系统被人认真想过。」

---

## 二、核心概念

**AN OBJECT MADE OF ITS OWN VARIABLES —— 一个由自己的变量构成的物体。**

主视觉是一件实时 WebGL 雕塑，但它的每一个视觉属性都不是凭空设计的，
而是直接取自这套系统自己的原语：

| 雕塑属性 | 取自 |
|---|---|
| 形体的柔和度 | 圆角尺度 `--radius-*`（4 → 32px，全系统偏大） |
| 表面色 | 品牌透明度阶梯 `rgba(190,114,127, .08 → .36)` |
| 边缘光 | 深色态品牌文字色 `#e1a3af` |
| 明暗关系 | 三档阴影 `--shadow-sm / md / lg` |
| 运动节奏 | 三条缓动曲线（标准 / 回弹 / 抽屉） |

它不是任何现成的「AI 球」「液态汞」「霓虹球体」。

它是柔软的、暖的、略带瓷感与金属感之间的物质 —— **玫瑰金属**，
不是水银。低粗糙度但不是镜面。边缘有极细的冷白到玫瑰的 Fresnel。

禁止：机器人、大脑、神经网络、发光球、星空、粒子雨、赛博朋克。

它的深色主题才是「另一面」。）

## 四、艺术方向

保留原提示词的：

- Neo Editorial / Swiss Typography / 编辑式网格
- 巨型排版与微型排版的强烈反差（8–16vw ✕ 9–11px）
- 大量留白、非对称网格、允许文字被裁切、允许 3D 穿过文字
- 精细 metadata、章节索引、hairline
- 滚动叙事、mask reveal、clip-path、空间层级
- 自定义光标（极克制，点 → 薄环）
- 60fps 优先、adaptive DPR、prefers-reduced-motion、移动端重新构图

放弃原提示词的：

- 近纯黑基底 → 改为系统真实画布 `#f2f4f7`（浅）与 `#1a1a1a`（深）
- 锋利无圆角 → 圆角是这套系统的**主张**，不是妥协，必须放大展示
- 液态汞 / 黑铬 → 玫瑰金属
- 「不要为了现代把所有东西变圆」→ 本项目相反：**要论证为什么这里应该圆**

## 六、字体

正文与 UI 沿用系统字体栈（Geist Latin + CJK 系统字体，`unicode-range` 分界）。

**展示层排版是宣传层，不是 UI 层** —— 允许 15vw，但必须在页面里说清楚
系统真正的 UI 字号阶梯是 10/11/12/13/13.5/14/15/18/24。不要让宣传排版
被误读成系统规范。

数字与令牌名走等宽栈：`SFMono-Regular, Consolas, Menlo, monospace`。

---

## 七、技术要求

- **单文件 HTML**，零外部依赖（字体仅在同源部署时启用）
- WebGL 走原生 GLSL，不引 Three.js —— 体积与可控性优先
- 不做 transform 伪平滑滚动（会破坏 `position: sticky`）；
  用真实 scrollY 驱动的 lerp 视差取代
- `IntersectionObserver` 暂停不可见的渲染
- 无 WebGL 时回退到 CSS 径向渐变，不留空洞
- 移动端：降低 DPR、降低 march steps、重新构图，不做等比压缩

## 八、最终标准

写代码前问自己：

1. 去掉「MolaGPT」这几个字，它是否仍然是一件完整的数字设计作品？
2. 页面上出现的每一个颜色、圆角、曲线，是否都能在设计系统里找到出处？

两个答案都必须是「是」。

第 2 条是这个项目和普通 Awwwards 风格站点的唯一区别，也是它存在的理由：

**它不是用某种风格去包装一套系统，它就是那套系统本身在展示自己。**
