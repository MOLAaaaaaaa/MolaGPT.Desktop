01

概览与层叠顺序

V2 没有单独的 design-system.css。这套系统是分层的：一份令牌 + 一层主题覆盖 + 若干组件表， 全部靠同一组 CSS 变量串起来。搞清楚谁在覆盖谁，比记住某个颜色更重要。

层文件职责
令牌层molagpt.css :root 品牌色、表面、文字、描边、阴影、过渡、侧栏宽度。唯一的真值来源。
主题层modern-clean.css Beta 视觉主题（body.beta-theme-active）：浮岛布局、扩展圆角阶梯、大量 !important 覆盖。它重定义了 radius-sm/md/lg。
组件层*-uikit.css / extensions.css
feature-notice.css / projects.css		 输入器、对话列表、扩展中心、功能通告、Workspace。只消费令牌，不新增令牌（--ext-shield 除外）。
兜底层molagpt_extra.css / _auth.css 历史遗留与业务态样式，多为 var(--x, 硬编码兜底) 写法。

加载顺序（后者覆盖前者）

bootstrap.min.css
  └─ molagpt.css              ← 令牌定义
      └─ molagpt_auth / _extra / _guide / _animations
          └─ modern-clean.css     ← 主题覆盖（含 radius 阶梯）
              └─ conversation-list-uikit.css
                  └─ composer-uikit.css
                      └─ extensions.css / feature-notice.css / projects.css

因为 modern-clean.css 排在 molagpt.css 之后、选择器同为 :root， --radius-sm/md/lg 的最终值来自它，而不是 molagpt.css 里写的那三个值。详见 §04 与 §16。

字体

西文走可变字重的 Geist，中文交给系统字体。关键在 unicode-range： Geist 只接管拉丁与通用标点，刻意避开 CJK 标点区，避免中文引号、书名号被西文字体渲染成半角错位。 

@font-face {
    font-family: 'Geist Latin';
    font-weight: 1 1000;            /* 可变字重 */
    font-display: swap;
    src: url('/v2/webfonts/GeistVariableVF.ttf') format('truetype');
    unicode-range: U+0000-024F, U+2000-206F, U+2190-21FF, U+2200-22FF, U+25A0-25FF;
}

body {
    font-family: 'Geist Latin',
        -apple-system, BlinkMacSystemFont, "Segoe UI",
        "Noto Sans CJK SC", "Noto Sans SC",     /* Android / Linux */
        "PingFang SC", "Hiragino Sans GB",      /* macOS / iOS */
        "Microsoft YaHei UI", "Microsoft YaHei",/* Windows */
        "Helvetica Neue", Helvetica, Arial, sans-serif;
}

两条硬约束

i
窗口 resize 时全局掐断动画。JS 给 body 挂 .resize-animation-stopper， 该类下所有 animation / transition 强制 none，解决拖窗卡顿和跨断点时侧栏宽度的诡异动画。 唯一例外是移动端侧栏的 transform，它以更高优先级豁免。

尊重 prefers-reduced-motion。通知组件已完整实现：过渡、位移、倒计时进度条全部关闭， 且直接把元素置为终态（opacity: 1），不会停在中间值。新组件照抄这个写法。

16

一致性备忘

整理过程中确认的几处问题，按会不会咬人排序。都是可查证的事实，不是风格偏好。

1
圆角令牌被定义两次且值不同。 molagpt.css 的 sm/md/lg = 6/10/16，modern-clean.css 的 = 12/16/20， 同为 :root、靠加载顺序决胜负。调整 CSS 引入顺序会静默改变全站圆角。 建议：删掉 molagpt.css 里那三行，只留一处。
2
语义色只在深色主题存在变量，且与组件硬编码值不一致。 --success-color: #4caf50（深色）vs 通知组件里的 #28a745（两个主题都用）。 建议：把四组语义色（前景 / 底 / 边，浅深各一套）提到令牌层，组件只引用变量。
3
画布底 #f2f4f7 与深色 #121212 是硬编码。 它是浮岛布局最外层的底色，却没有对应令牌，深色主题也没显式定义。建议补 --canvas。
4
--text-tertiary 被引用但从未定义。 extensions.css 已经写了兜底 var(--text-tertiary, #8a8f98) 并留言"站点后续补上会自动生效"。补一个就行。
5
没有间距与字号令牌。 实测间距集中在 2/4/6/8/10/12/16/20/24，字号集中在 10/11/12/13/13.5/14/15/18/24。 其中 13 与 13.5 并存、8px 与 10px 圆角绕开令牌直写，属于可以顺手收敛的部分。
6
