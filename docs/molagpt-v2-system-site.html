0001

物体
没有
固定形状

你在整页背后看到的那个东西，不是找来的素材。 它的每一个视觉属性都直接取自这套系统自己的原语 —— 没有一处是为了「看起来高级」而额外加的。

这也是这套系统唯一想说的话：先定义材料，再谈造型。 当颜色、圆角、阴影、曲线都只有一个出处， 界面就不需要每次重新决定长什么样。

0002
Color

一条阶梯
不是一张色板

#be727f

一个偏灰的玫瑰粉。饱和度刻意压低，所以它可以大面积用作交互态而不刺眼 —— 这是整套视觉能保持安静的前提。

系统里几乎所有「品牌色的柔和态」都不是新色号，而是同一个 RGB 上的一条透明度阶梯。 新组件应该从这条阶梯里取值，而不是自己再调一个粉。

深色主题下阶梯换用 rgba(207,137,150, α)， 并整体加重 4–8 个百分点 —— 因为深底上的低透明度品牌色几乎看不见。

0003
Type

一条画在
码位上的边界

Geist・字体

西文走可变字重的 Geist，中文交给系统字体。真正的设计决策在 unicode-range 那一行：Geist 只接管拉丁与通用标点， 刻意避开 CJK 标点区。

否则中文引号、书名号会被西文字体渲染成半角，在整段中文里错位。 这是一行注释就能说清、但漏掉就会天天硌人的细节。

十档

唯一一套命名完整的尺度令牌。整体偏大 —— 主舞台 32px、侧边栏 24px、输入器 20px —— 「浮岛」质感几乎全部来自这里。

同名令牌被定义了两次。 molagpt.css 里 sm/md/lg = 6 / 10 / 16px，modern-clean.css 里 = 12 / 16 / 20px。 两者都挂在 :root，特异性相同，最终由加载顺序决定 —— 线上生效的是后者。 这意味着只要有人调整 CSS 引入顺序，全站圆角会整体变小，而且不会报任何错。

两条硬约束

窗口 resize 时全局掐断动画。 JS 给 body 挂 .resize-animation-stopper，该类下所有 animation / transition 强制 none， 解决拖窗卡顿与跨断点时侧栏宽度的诡异动画。唯一例外是移动端侧栏 transform。

尊重 prefers-reduced-motion。 通知组件已完整实现：过渡、位移、倒计时进度条全部关闭， 并把元素直接置为终态 —— 不会停在中间值。新组件照抄这个写法。

0010
Errata

诚实
是系统的一部分

以下是整理过程中确认的问题，按会不会咬人排序。都是可查证的事实，不是风格偏好。 一套不敢列勘误的设计系统，通常只是没人认真看过。

01
圆角令牌被定义两次且值不同
molagpt.css 的 sm/md/lg = 6/10/16，modern-clean.css 的 = 12/16/20，同为 :root、靠加载顺序决胜负。调整 CSS 引入顺序会静默改变全站圆角。建议删掉 molagpt.css 里那三行，只留一处。
02
语义色只在深色主题存在变量，且与组件硬编码值不一致
--success-color: #4caf50（仅深色）对上通知组件里的 #28a745（两个主题都用）。建议把四组语义色的前景 / 底 / 边，浅深各一套，提到令牌层。
03
画布底是硬编码
#f2f4f7 是浮岛布局最外层的底色，却没有对应令牌；深色主题也没显式定义。建议补 --canvas。
04
--text-tertiary 被引用但从未定义
extensions.css 已经写了兜底 var(--text-tertiary, #8a8f98)，并在注释里留言「站点后续补上会自动生效」。补一个就行。
05
没有间距与字号令牌
实测间距集中在 2/4/6/8/10/12/16/20/24，字号集中在 10/11/12/13/13.5/14/15/18/24。其中 13 与 13.5 并存、8px 与 10px 圆角绕开令牌直写，属于可以顺手收敛的部分。
06
主题层大量使用 !important
modern-clean.css 与两个 uikit 表几乎每条声明都带 !important，这是为了压过 bootstrap 与旧样式，代价是后续组件只能继续用 !important 才改得动。新组件尽量写在最后加载的表里、用更具体的选择器，而不是继续叠。
给新组件的最短检查表
颜色只从阶梯取中性用 --bg-* / --text-*，不新调色号
圆角只用 --radius-*不写裸数值
过渡默认 --transition只在需要被注意时用回弹
写完浅色立刻看深色中性擦色与品牌透明度都要单独加重
补 reduced-motion并把元素直接置为终态
新表挂在加载链末尾别往 molagpt.css 里塞
